## 7. Falsification Probes (P-CONT-1)

### P-CONT-1.A — Low-contrast injection

**Probe:** Added `ContrastPair { pair_id: "PROBE_LOW", fg: Color::WHITE, bg: Color::from_rgb(0.9, 0.9, 0.9), class: ContrastClass::Body }` to the PAIRS table.

**Command:** `UI_CONTRAST_MODE=gate cargo test -p ui --test contrast --no-default-features --features live -- all_theme_pairs_meet_wcag --nocapture`

**Result:** FAILED. Panic excerpt:
```
contrast assertion failed:
  PROBE_LOW = 1.25 < threshold 4.5
  fg_3_on_panel_raised_dark = 3.75 < threshold 4.5
  ...
```

Probe ratio: 1.25 (WHITE on #E6E6E6, confirming the brief's note that `Color::from_rgb(0.9, 0.9, 0.9)` = #E6E6E6 not #E5E5E5; ratio 1.25 not 1.07 — probe is FUNCTIONAL per the handoff clarification). Gate correctly rejects. **Reverted verbatim; clean PASS confirmed.**
