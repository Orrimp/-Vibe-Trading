### Notable per-arm observations

**`v0.8.vote.trend_pair` (predicted-null control — both trend):** Realized Sharpe 1.075, +1.07% return, 167 trades, Fragile. This is the HIGHEST Sharpe among any active arm. Notably, `trend_pair` ranks ABOVE its members: `v0.5.macd` (Sharpe 0.966) and `v0.sma` (-0.038). The correlated-trend pair did materially better than one of its members (`v0.sma`). However, it still came back Fragile — the bootstrap p5 Sharpe is still < 0. **Decorrelation-thesis implication:** the trend∧trend control performing comparably to the trend∧mean-revert pairs is relevant (see Verdict on Prediction below).

**`v0.8.vote.tr_mr_macd_rsi` (trend∧mean-revert, Unanimous{n:2}):** Sharpe 0.000, 0 trades, 0 return. The trend follower (MACD) and mean-reverter (RSI) never simultaneously agreed over the entire H1-2024 window. Strict consensus was never reached — the OQ-3 "sat in cash" honesty case, exactly as predicted. Fragile.

**`v0.8.vote.tr_mr_sma_bb` (trend∧band-reversion, Unanimous{n:2}):** Sharpe -2.761, -1.22% return, 110 trades, Fragile. Unlike `tr_mr_macd_rsi`, this arm DID trade (110 times) but produced the worst performance in the field. SMA and BBands apparently agreed in regime transitions that proved unfavorable.

**`v0.8.vote.any1of4` (k-ladder rung 1, loosest — long if ANY fires):** Sharpe 0.041, +0.09%, 237 trades. As predicted, the loosest arm shows the highest trade count (most exposure, lowest decorrelation benefit). Still Fragile.

**`v0.8.vote.k2of4` (k-ladder rung 2, balanced quorum):** Sharpe 0.495, +0.62%, 337 trades. Interestingly the highest trade count of all arms (337). Still Fragile.

**`v0.8.vote.k3of4` (k-ladder rung 3, strict — broad agreement):** Sharpe -1.431, -0.31%, 32 trades. Tightest quorum, fewest trades, but negative performance. Still Fragile.

### Equity Curve Summary

Buy-and-hold dominates on the 2024 H1 BTC bull run (+47.78%). All active strategies capture only a small fraction of that upside (best active arm: `trend_pair` at +1.07%). The ensemble arms with Unanimous{n:2} strict consensus show a sharp bifurcation: `tr_mr_macd_rsi` never triggered (0 trades), while `tr_mr_sma_bb` triggered 110 times to -1.22%. The k-ladder shows trade-count monotonically decreasing as k rises (k1: 237, k2: 337, k3: 32) but k2of4 anomalously has MORE trades than k1of4 — plausibly because the 4-member Majority with k=2 in practice fires when any 2 of 4 agree, and in a strong trending market that creates more signal churn than a simple any-1 rule.
