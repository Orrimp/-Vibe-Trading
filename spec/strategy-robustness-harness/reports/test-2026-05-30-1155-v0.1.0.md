### Gate 3 — FP-C2.1 Divergence Gate (the noop-fix falsification probe — SCRUTINIZED)

**Test structure and genuine-guard verification:**

The harness has TWO complementary tests:

1. `rn6a_divergence_gate_passes_with_distinct_seeds` (N=20, MASTER=0xC0FFEE): builds 20 paths with distinct seeds via `build_path_metrics_n(MASTER, N, N_BARS, seed_override=None)`, computes spread = p95_sharpe − p5_sharpe, asserts `spread >= 0.01`. This is the **live positive** case.

2. `fp_c2_1_degenerate_seeds_have_zero_spread` (N=20, same MASTER): builds 20 paths all with the SAME seed (`seed_override = Some(path_seed(MASTER, 0))`), asserts `spread.abs() < 1e-9`. This is the **degenerate negative** case.

**Genuine-guard analysis:** The `build_path_metrics_n` helper with `seed_override=Some(s)` passes `s` to all 20 calls to `synthetic_bars(seed, n_bars)`. Since `ChaCha20Rng::seed_from_u64` is deterministic, identical seeds produce identical bar sequences, identical equity curves, and therefore identical per-path metrics — spread collapses to EXACTLY 0.0. The gap between 0.0 and the epsilon 1e-9 is 9 orders of magnitude.

**Mutation reasoning:** If the `seed_override` path in `build_path_metrics_n` were removed (so all paths used distinct seeds even under `Some(fixed_seed)`), the degenerate test would fail (spread > 0). Conversely, if the seed derivation in the production code (`derive_path_seed`) were broken to return the same constant for all j, `rn6a` would fail (spread ≈ 0 < 0.01). The two tests bracket the falsification: one must be high, one must be low.

**Comparison to C1 FP-C1.5 standard:** C1's shared-index guard showed correlation collapse to −0.079 (decorrelated) vs preserved source co-movement under the real path. C2's FP-C2.1 shows spread collapse to EXACTLY 0 (N=20 identical paths) vs spread 0.079+ in the real 20-path case. The evidence is structurally equivalent: degenerate input → degenerate output (near-zero), real input → non-degenerate output (well above epsilon). The guard is **GENUINE**, not theater.

**Verdict: FP-C2.1 is a REAL guard.**
