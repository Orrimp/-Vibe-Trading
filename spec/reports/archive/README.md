# Archived tester reports

Per AGENT.md the project's tester reports are immutable dated audit
records. As the report set grows, older reports for shipped features
are archived here in compressed form to keep `spec/reports/` listings
scannable while preserving full audit history.

## Archives

### `pre-lumen-tester-reports-2026-04-to-05-03.tar.gz` (created 2026-05-08)

to the lumen-design-adoption initiative kickoff. Compressed from
432 KB → 99 KB (77% smaller).

Each report is the canonical tester ratification artefact for the
feature it names; all are referenced as shipped invariants in the
cross-feature invariants table at

```bash
tar -tzf spec/reports/archive/pre-lumen-tester-reports-2026-04-to-05-03.tar.gz
```

The originals were also preserved in git history; `git log
--diff-filter=D --name-only -- 'spec/reports/test-2026-04-*.md'`
identifies the deletion commit if you need to recover via
`git show <sha>:spec/reports/<filename>.md`.

## What's NOT archived

- Lumen-phase tester reports (`test-2026-05-04*` through
  `test-2026-05-07b-*`) — recent, load-bearing for the audit trail
  of the just-shipped initiative; some are first-pass FAIL reports
  preserved alongside their PASS counterparts per the established
  audit-discipline pattern.
- Backtest reports (`spec/reports/backtest-*.md`) — anchored via
  `spec/anchors.toml`; deleting them would break `verify_anchors.sh`.
- Success reports (`spec/reports/success/`) — operator-facing
  weekly summaries; auto-generated by the `reports` crate at v1+.
- Screenshots and screenshot manifests (`spec/reports/screenshots/`).

Future archives accumulate here with their own dated tarball.
