# Reports

Append-only. **Never edit** a report after it is written — create a new one.

Naming:

- Test runs: `test-<YYYY-MM-DD-HHMM>-<feature-slug>.md`
- Analyst research: `analysis-<YYYY-MM-DD>-<topic>.md`
- Architecture decisions: `adr-<NNNN>-<short-title>.md`

Artifacts (CSVs, plots) go under `artifacts/<run_id>/`.
