## 4. Falsification Probes (load-bearing — independent tester re-runs)

### FP-C1.1 — Same-seed determinism (ADR-0051 D1 keystone)

**Test:** `synth::bootstrap::tests::fp_c1_1_same_seed_deterministic`

**What the test does (read and verified):** calls `bgen.generate(&universe, 50, 0xCAFE_DEAD)` TWICE
with the identical seed and asserts `b1.close == b2.close` element-wise for every bar in every symbol.
This is the STRONG form — identical inputs ⇒ byte-identical output, not just "different seed differs".

**Result:** PASS. The same-seed-identical assertion holds.

**Note:** FP-C1.2 (`fp_c1_2_different_seed_diverges`) confirms the inverse — different seeds produce
at least one differing close price. Together they satisfy R2.4 and ADR-0051 D1.

### FP-C1.5 — Shared-index co-movement guard (Q-MCB-2, methodologically load-bearing)

**This is the most important methodological check.** For a cross-sectional momentum strategy,
per-symbol-independent resampling destroys contemporaneous correlation and makes the ensemble
unrealistically diversified in a crash (understates tail co-movement, optimistic p95 MaxDD).

**Mutation probe (Edit-then-Edit-back, no git mutations):**

The shared-index loop in `bootstrap.rs` (lines 212–302) was temporarily mutated from:
- Drawing ONE shared `idx_seq` for the whole path, then applying it to ALL symbols

To:
- Drawing a FRESH per-symbol `ChaCha20Rng::seed_from_u64(path_seed.wrapping_add(sym_i * 0x9E37_79B9))`
  and an INDEPENDENT index sequence per symbol

**Observed failure with mutation applied:**

```
test synth::bootstrap::tests::fp_c1_5_shared_index_co_movement ... FAILED

---- synth::bootstrap::tests::fp_c1_5_shared_index_co_movement stdout ----
thread panicked at crates/data/src/synth/bootstrap.rs:684:9:
FP-C1.5: shared-index resampled BTC/ETH correlation=-0.0791 must be > 0.5
```

The correlation collapsed from >0.95 (source series) to -0.079 (random sign noise) when
per-symbol-independent resampling was applied. The co-movement guard is **NOT theater** — it
is correctly wired and correctly detects the decorrelated null.

**After restore:** file reverted verbatim. `git diff --stat` confirms only
`data/yahoo/REVISION.toml` has outstanding diff (pre-existing, not part of C1). All 23 synth
tests pass at 23/23 post-restore.

**Verdict on FP-C1.5:** GENUINE — the shared-index wiring is real and the guard catches its removal.

### Block-length=1 degeneracy (FP-C1.3)

## 10. Design-Level Confirmations

- **Bootstrap on log-returns with documented Decimal-f64 boundary:** Confirmed. `bootstrap.rs`
  computes log-returns in f64 (`(c1/c0).ln()`), applies the stationary bootstrap index sequence
  in f64 return-space, then rounds to `Decimal` via `Decimal::try_from(f64)` at the `Bar`
  boundary. The `to_dec` helper and `price_or_min` wrapper implement the existing
  `synthetic_bars_hourly` `to_dec` pattern. ADR-0003 compliant.
- **GbmPathGen is a NEW, independent impl (NOT a lift of existing GBM):** Confirmed. `gbm.rs`
  is a fresh file with no call to `synthetic_bars_hourly`, `synthetic_bars`, or
  `synthetic_bars_det`. The 3 existing functions are byte-unchanged (verified by commit stat
  and `git log -- momentum.rs main.rs determinism.rs` showing zero commits since C1).
- **ChaCha20Rng is the ONLY RNG used:** Confirmed in all three synth source files. No
  `thread_rng`, `OsRng`, `SmallRng`, or wall-clock usage. ADR-0002 compliant.
- **One ChaCha20Rng per path (ADR-0051 D1 composition):** Confirmed in `bootstrap.rs`: a single
  `ChaCha20Rng::seed_from_u64(path_seed)` is created, the shared index sequence draws from it,
  and price reconstruction is deterministic arithmetic with no further RNG calls. `GbmPathGen`
  derives per-symbol seeds via `path_seed.wrapping_add(sym_i * 0x9E37_79B9)` (ADR-0051 D1
  / momentum.rs:245 idiom) and creates one RNG per symbol.
- **`selected_block_length` is `Some(L)` for bootstrap, `None` for GBM:** Confirmed in
  `mod.rs` struct definition and both generator impls.
