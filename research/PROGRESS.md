## The 9 topics

1. **strategies** — quant/algo strategies, factors, microstructure, execution.
2. **backtesting** — backtest METHODOLOGY: overfitting metrics (DSR/PBO/CSCV), CV,
   data-snooping, walk-forward, cost/impact modeling.
3. **ml-trading** — classical/shallow ML, feature engineering, forecasting pipelines.
4. **deep-learning** — deep nets + reinforcement learning for trading.
5. **data** — the DATA itself: test/train/validation splits, leakage, overfitting
   (data angle), Monte-Carlo & synthetic data generation, point-in-time/as-of data,
   labeling, data quality, alt-data sourcing. (Overlaps backtesting by lens, not scope.)
6. **evolution** — evolutionary/genetic algorithms, optimization, symbolic regression,
   automated alpha/strategy search, strategy-UPDATING (NOT LLMs).
7. **llms** — LLMs as likelihood-computing neural nets in finance: agents, sentiment,
   reasoning, benchmarks; and the open question **has anyone trained an LLM ON
   financial time series (vs. text)?** — LLM-for-time-series architectures.
8. **risk-and-sizing** — Kelly/fractional-Kelly, vol-targeting, drawdown control,
   risk parity, bet sizing, money management ("sizing > signal").
9. **crypto-market-structure** — funding rates, perp basis, crypto volatility &
   liquidity, on-chain metrics, stablecoins, crypto market regimes/microstructure.

## How to resume / run the next round

The ledgers ARE the state. Each round:

```bash
grep -rc '^### ' research/*/papers.md     # per-topic counts (exclude llm-and-evolution once retired)
```

For each topic **< 100**, spawn a `researcher` agent (registered in
`.claude/agents/researcher.md`) told to **read its ledger first, skip titles already
listed**, and add a batch (~25–40) toward 100, writing incrementally. For `llms` /
`evolution` the first round also **migrates** the relevant entries from
`research/llm-and-evolution/papers.md` (renumber from [1]) before extending. After
each round: regenerate this file + `papers.md`, commit.
