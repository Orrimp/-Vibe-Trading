## Findings (NEW this audit)

### F-A — The enforcement perimeter is 2 scripts wide, and one unwired gate is RED (P1)

`.github/workflows/ci.yml` and `.githooks/pre-commit` between them invoke exactly **two** of the
repo's gate scripts: `spec_lint.py` and `verify_anchors.sh`. Seven others run **only when an agent
remembers** — which is precisely the condition bug-log **#66** documented ("what discipline-only
enforcement ships") and **#84** re-proved four weeks later.

The sharpest consequence: **`scripts/check_no_clocks_in_ui_tests.sh` FAILS at HEAD.**

```
FAIL  crates/ui/src/widgets/chart.rs:251  — unwhitelisted 'UtcOffset::current_local_offset'
FAIL  crates/ui/src/widgets/chart.rs:301  — unwhitelisted 'UtcOffset::current_local_offset'
FAIL  crates/ui/src/widgets/chart.rs:2285 — unwhitelisted 'UtcOffset::current_local_offset'
```

`git log -L` dates the `:301` call site to **`f5fec84`, 2026-05-20** (`ship(chart-x-axis-local-time)
v1.11.0`). The gate has therefore been red for **~89 days** without anyone noticing, because
nothing runs it. The call is `current_local_offset().unwrap_or(UtcOffset::UTC)` on the chart
render path — reachable from the snapshot path the gate exists to protect, and a plausible source
of machine-dependent pixel output (which interacts directly with the AD-10 rendered-pixel
non-negotiable and with #88 below). The fix is likely one line — either a `// CLOCK-OK: <reason>`
marker if the fallback genuinely makes snapshots deterministic, or an injected offset. **The
finding is not the three lines; it is that 89 days elapsed.**

Also unwired: **`adr_registry_check.py`** — CLAUDE.md's AD-18 non-negotiable says ADR registration
is "enforced by `scripts/adr_registry_check.py`", but no automation invokes it; and
**`check_no_secrets_in_llm_artifacts.sh`**, the mechanical arm of AD-19's "no secrets in git".
Both are green today. Green-and-unrun is a coin-flip, not a guarantee.

**Recommended shape:** add the five cheap stdlib/bash gates (`adr_registry_check.py`,
`check_determinism_anchors.py`, `check_no_raw_asof_join.sh`, `check_no_secrets_in_llm_artifacts.sh`,
`check_no_clocks_in_ui_tests.sh`) to the existing ubuntu "Governance gates" CI step — which already
carries the load-bearing `shell: bash` pipefail fix — after fixing or whitelisting the 3 clock
violations. Owner: operator → dev.

### F-B — `spec_lint`'s trace-anchor check is type-blind; 7 `shipped` rows are silently unvalidated (P2)

`scripts/spec_lint.py:596` reads:

```python
raw_anchors = row.get("anchors", [])
if isinstance(raw_anchors, list):
    for anc in raw_anchors:
        ...
        if anc not in anchors:
            report.add("trace-broken-path", ...)
```

Every *other* trace field (`product`, `arch`, `crates`, `tests`) is validated through a
`isinstance(val, str) / elif isinstance(val, list)` pair that handles both shapes. `anchors` is
list-only, so a bare-string value falls through the `if` and is **never checked**. Seven `shipped`
rows do exactly that, and their strings are free text, not scenario names:

| Row id                                    | `anchors` value | State   |
|-------------------------------------------|-----------------|---------|
